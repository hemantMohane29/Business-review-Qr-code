## How to Get Your Google Review URL

### Step-by-Step:

1. **Go to:** https://business.google.com
2. **Sign in** with the Google account that owns your business
3. **Click** on your business name
4. **Look for** one of these buttons:
   - "Get more reviews"
   - "Ask for reviews"
   - "Share review form"
5. **A popup appears** with your review link
6. **Copy the URL** - It looks like:
   ```
   https://g.page/r/CbXXXXXXXXXXXXXX/review
   ```
   or
   ```
   https://search.google.com/local/writereview?placeid=ChIJXXXXXXXXXXXXXXX
   ```

### Don't Have Google Business Profile?

1. **Create one:** https://business.google.com
2. **Click:** "Add your business to Google"
3. **Fill in:** Business name, category, location, phone
4. **Verify:** Google will send verification code (postcard/phone/email)
5. **Wait:** 5-7 days for postcard verification
6. **Then:** Get your review URL as above

## Phone Number Formats by Country

### India 🇮🇳
```
+919876543210
```
- Start with +91
- Then 10-digit mobile number
- No spaces, no dashes

### USA 🇺🇸
```
+11234567890
```
- Start with +1
- Then 10-digit phone (area code + number)

### UK 🇬🇧
```
+447123456789
```
- Start with +44
- Remove the leading 0 from UK number
- Example: 07123456789 becomes +447123456789

### UAE 🇦🇪
```
+971501234567
```
- Start with +971
- Then 9-digit mobile (without leading 0)

### Australia 🇦🇺
```
+61412345678
```
- Start with +61
- Remove the leading 0 from Aussie number

### More Countries
- Canada: +1 (same as USA)
- Germany: +49
- France: +33
- Singapore: +65
- Malaysia: +60

## Get Free Gemini AI Key

### Steps:

1. **Go to:** https://aistudio.google.com/app/apikey
2. **Sign in** with any Google account (doesn't need to be business account)
3. **Click:** "Create API key"
4. **Select:** "Create API key in new project"
5. **Copy** the key - starts with `AIza`
6. **Paste** in admin panel settings

### Free Tier Limits:
- 15 requests per minute
- 1,500 requests per day
- More than enough for a physical QR standee!

### Note:
- System works WITHOUT API key
- AI key just makes reviews sound better
- Supports multiple languages with AI key

## Sample Goodwill Voucher Codes

When customers give 1-3 stars, you can offer them a discount code:

- `CARE15` - 15% off next visit
- `SORRY20` - 20% off
- `FEEDBACK10` - 10% discount
- `VALUEDU` - Free upgrade
- `OOPS` - Free dessert/service
- `SORRY` - Complimentary item

**Edit these** in the admin panel settings!
