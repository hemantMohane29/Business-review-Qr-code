## 🎯 Quick Start Guide

### Step 1: Access Admin Dashboard
1. Go to: https://businessreviewqrcode.vercel.app/admin.html
2. Enter PIN: `admin1234`
3. Click "Unlock Dashboard"

### Step 2: Add Your Business
1. Click "Businesses" tab
2. Click "Add New Business"
3. Fill in:
   - Business Name
   - Business Type
   - Google Review URL
   - Manager WhatsApp (optional)
   - Manager Email (optional)
   - Gemini API Key (optional)
4. Click "Save"

### Step 3: Get Customer URL
After saving, you'll get a URL like:
```
https://businessreviewqrcode.vercel.app/customer-review.html?b=abc123xyz
```

### Step 4: Generate QR Code
1. Go to "QR & Standee" tab
2. Your QR code appears automatically
3. Click "Download QR Code"
4. Print (minimum 5cm x 5cm)
5. Display on counter/table

## 🆘 Troubleshooting

### QR Code Not Working?
✅ Check URL is complete with `?b=BUSINESS_ID`
✅ Ensure QR code is at least 5cm x 5cm when printed
✅ Test URL in phone browser first

### Admin Not Loading?
✅ Check URL is exactly: `.../admin.html`
✅ Clear browser cache
✅ Try incognito/private mode

### Customer Page Shows "Not Configured"?
✅ Add business in admin panel first
✅ Use correct business ID in URL
✅ Refresh page after configuration
